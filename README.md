# KTB Excel RTD Monitor

## 현재 판정 (2026-10-15)

관찰·연구용 프로토타입입니다. 기관 실거래용 승인 신호, 현물 베이시스 엔진, 계좌 통합 리스크 시스템이 아닙니다. 최종 감사에서 보유 120,102행에 품질 규칙을 적용한 결과 완료 분봉은 최대 30개였고, 기본 60분 준비조건을 충족한 연구 신호/가상 거래는 0건입니다. 기존 페이퍼 성과를 검증된 수익으로 해석하지 마세요.

한국 국채선물 3Y/10Y의 Excel RTD 실시간 호가와 시장 체결가를 Python으로 수집·분석하는 관찰용 프로토타입입니다. 자동주문·주문 API·실거래 기능은 포함하지 않습니다. 수동 주문 운영에 맞춰 Excel은 기본 1초마다 읽고, 중복 호가는 5초 heartbeat로 축약하며 CSV·SQLite는 1초 단위로 묶어 저장합니다. Excel COM 읽기 실패는 실패한 경우에만 0.15초·0.35초의 짧은 내부 재시도를 먼저 수행합니다. 모두 실패한 연결 오류만 3→4→5초(최대 5초) 간격으로 재연결하며, 정상 관측이 돌아오면 1초로 복귀합니다. 로그에는 기본 호가 블록과 추가 RTD 블록 중 실패 위치를 구분해 남깁니다.

당일 10Y–3Y 스프레드 추이는 `KTB_10-3스프레드_그래프.bat`으로 별도 실행할 수 있습니다. 이 BAT 하나만 실행해도 수집기가 백그라운드로 함께 시작되며, 이미 수집기가 실행 중이면 중복 실행하지 않습니다. 상단에는 현물 3년·10년 수익률과 선물 10년–3년 수익률차를 큰 카드로 표시해 목적에 맞는 값만 한눈에 보이게 했습니다. 현재 날짜의 `snapshots_enhanced_YYYYMMDD.csv`를 읽어 KST 기준 1분별 마지막 유효 관측을 표시하며, 현물 금리차와 선물 수익률차를 같은 축(bp)으로 겹쳐 그립니다. Y축은 0.5bp 그리드, X축은 10분 간격 그리드로 표시하고, 마우스를 올리면 가장 가까운 분의 시각과 두 수치가 툴팁으로 나타납니다. 하단에는 3Y·10Y 외국인 누적 매수·매도 수량의 1분 변화량을 각각 은색 막대로 표시합니다. 상단에서 60분·120분·전체 구간을 전환할 수 있고, 파일이 저장 중 잠시 잠겨도 마지막 정상 화면을 유지하며 연결 상태를 표시합니다. 그래프 창을 닫으면 이 BAT가 시작한 수집기도 종료됩니다. 수집기·대시보드와 독립적이고 5초마다 파일만 다시 읽으므로 Excel COM 연결이나 수집 주기에 영향을 주지 않습니다. 데이터 공백은 보간하지 않습니다.

그래프 창의 상단 작은 카드는 각 선물의 외국인 누적 순매수(`매수 누적 − 매도 누적`)도 3년·10년으로 나눠 보여줍니다. 누적값은 현재 포지션 흐름의 참고치이고, 하단 막대는 전 분 대비 변화량이므로 두 값을 혼동하지 않아야 합니다. 현물·선물 카드의 단위는 수익률 `%` 또는 수익률차 `bp`, 외국인 카드는 계약입니다.

구성 논리:

2026-10-29 성능 개선으로 그래프는 파일을 백그라운드에서 읽고, 처음 불러온 뒤에는 추가된 행만 처리합니다. 카드도 같은 읽기 결과로 갱신하며, 화면 크기 변경 시에는 저장된 그래프만 다시 그립니다. 과거 파일 내용을 직접 수정한 경우 상단 `전체 다시 읽기`를 누르면 됩니다. 날짜 변경·파일 교체·축소는 자동 재로딩하고, 마지막 줄이 저장 중이면 완성될 때까지 기다립니다.

1. `spread_chart_launcher.py`가 기존 `collector.lock`을 존중하면서 수집기를 자식 프로세스로 시작합니다. 이미 수집기가 있으면 자식은 즉시 종료하고 기존 기록자를 사용합니다. 그래프를 닫을 때는 이 실행기가 직접 시작한 자식만 종료합니다.
2. `spread_chart.py`는 당일 `snapshots_enhanced_YYYYMMDD.csv`를 KST 날짜로 필터링하고, 같은 분의 마지막 유효 관측만 남깁니다. `cash_spread_bp`·`futures_yield_spread_bp`가 비어 있으면 원천 3Y/10Y 금리·수익률로 재계산합니다.
3. 외국인 하단 막대는 각 만기별 누적 순매수의 전 분 대비 차분을 사용합니다. 3Y와 10Y를 별도 색상·막대로 그려 합산 수급으로 뭉개지지 않도록 했습니다.
4. 파일을 읽는 동안 잠김·부분 저장·일시 오류가 발생하면 마지막 정상 프레임을 유지하고 상태 배지를 `재시도 중`으로 바꿉니다. 갱신 예약과 읽기 작업은 각각 하나만 유지하며, 창 크기 변경으로 중복 타이머가 쌓이지 않습니다. 카드용 별도 전체 파일 재읽기는 제거했고, 데이터 변화가 없으면 차트 재생성을 생략합니다.

일시적인 Excel/RTD 읽기 공백 중에는 화면이 신호를 차단합니다. 정상 관측이 돌아오면 공백 전후 가격변화를 하나의 수익률로 연결하지 않고 확인 지속시간도 다시 시작하지만, 같은 날 이미 완성된 1분 변동성·RV 관측 이력은 유지합니다. 따라서 짧은 COM 재연결 때문에 60분 관측창 전체가 매번 초기화되지는 않습니다.

수집기는 출력 폴더별 잠금으로 같은 CSV·SQLite에 두 프로세스가 동시에 기록하지 못하게 합니다. `추가RTD` 시트 연결은 첫 확인 뒤 재사용하고, 시트 객체가 무효화되면 다시 찾습니다. Excel 계산 모드와 RTD 갱신 간격은 다른 열린 통합문서에도 영향을 줄 수 있어 프로그램에서 변경하지 않습니다.

## 빠른 실행

1. 32비트 데스크톱 Excel에서 `국채선물 호가창.xlsx`를 엽니다.
2. CheckExpert RTD 값이 표시되는지 확인합니다.
3. `KTB_모니터_시작.bat`을 한 번 더블클릭합니다.

통합 실행기가 수집기를 보이지 않게 시작한 뒤 대시보드를 엽니다. 대시보드를 닫으면 통합 실행기가 시작한 수집기도 함께 종료됩니다. 독립형 10Y–3Y 그래프가 먼저 수집기를 실행 중이어도 기존 수집기에 연결해 대시보드만 추가로 열 수 있으므로 두 창을 동시에 사용할 수 있습니다. 대시보드 자체가 이미 열려 있으면 별도 잠금으로 중복 창을 막습니다. 실행 오류와 수집 상태는 `data\launcher.log`에 기록하며, 2MB를 넘으면 직전 로그 하나(`launcher.log.old`)만 남기고 자동 교체합니다.

현재 workbook의 `추가RTD!B1:B10`에는 현물 3Y/10Y 체결수익률, 3Y/10Y 외국인 누적 매수·매도, 선물 체결가·선물수익률이 연결되어 있습니다. 추가 RTD 금리나 선물 체결가가 일시적으로 0·공란·오류 값이면 해당 지표와 관련 차이는 `N/A`로 표시하고 정상 호가 수집은 계속합니다. 유효한 값이 들어오면 재시작 없이 다시 계산합니다. 외국인 누적 거래량의 0은 유효한 값입니다. 다만 핵심 선물 호가의 0은 유효한 시세로 보지 않으므로 호가 자체가 잘못된 경우는 수집을 보류합니다. 수집기는 KST 날짜별 `data\snapshots_enhanced_YYYYMMDD.csv`와 같은 이름의 SQLite에 저장합니다. 대시보드는 시작 시 **오늘 날짜 파일의 외국인 수급과 변동성/RV 관측 이력**을 복원합니다. 프로그램이 꺼진 동안의 미관측 변화는 계산에서 연결하지 않으며, 일반 알림과 과거 합의신호도 재생하지 않고 새 관측부터 다시 판단합니다.

## 대시보드 화면

상단에는 3년·10년 선물 체결가, 선물 수익률 차, 현물 금리차가 표시됩니다. 선물 수익률 차는 `10년 선물 수익률 − 3년 선물 수익률`을 bp로 바꾼 값입니다. 기존 선물 **가격차(pt) 알림**은 변경하지 않았습니다. 아래 탭은 `금리차 위치 / 상대가치 / 외국인 수급 / 변동성 · 위험 / 호가 · 비용` 순서입니다. 코드 변경을 적용하려면 대시보드를 닫아 통합 실행기를 종료한 뒤 `KTB_모니터_시작.bat`을 다시 실행합니다.

대시보드의 **금리차 위치** 탭은 `추가RTD` 현물 3년·10년 체결수익률로 10년−3년 차이(bp)를 계산합니다. 완료된 분의 마지막 관측값을 5분·60분 기준으로 삼아 평균 대비 거리와 Z-score를 표시하고, 현재값의 5분·15분 변화를 보여줍니다. 해당 분 수가 채워질 때까지 준비 중이며, 누락·지연 데이터 뒤에는 다시 준비합니다. 60분 기준은 장중 관측용입니다.

**상대가치** 탭은 선택 입력 `cash_5y_yield_pct`가 연결되면 `5Y − (5/7×3Y + 2/7×10Y)` 현물 곡률을 표시합니다. 5년 현물은 곡률 기준점이며 거래 가능한 5년 선물로 간주하지 않습니다. 동시에 3년·10년 각각의 `선물수익률 − 현물수익률`과 두 값의 차인 교차 베이시스를 계산합니다. 완료 분봉 60분 창에서 평균·표준편차·z-score와 AR(1) 관측 반감기를 표시하고, 자동 DV01 정수 패키지의 현재 호가 간격으로 근사 왕복비용과 손익분기 교차 베이시스를 계산합니다. 이는 캐리·repo·경과이자·실제 현물 호가를 포함한 무위험 차익가격이나 주문 신호가 아닙니다.

5년 현물 연결에는 `extra_settings.json`의 `cash_5y_yield_pct`가 필요하고 `cash_5y_time`, `cash_5y_bond`는 선택사항입니다. 원천 동시성 검사를 위해 `cash_3y_time`, `cash_10y_time`, `3y_trade_time`, `10y_trade_time`도 권장합니다. 새 열을 처음 연결하는 날 이미 같은 날짜 CSV가 있으면 저장 스키마 보호가 이어쓰기를 거부하므로 장 시작 전 또는 다음 거래일에 연결하거나 기존 당일 파일을 보관 위치로 옮긴 뒤 시작해야 합니다.

**외국인 수급** 탭은 당일 저장된 관측 기록에서 누적 매수·매도 추정가격과 주구간을 복원하고, 최근 5·15·60분의 순매수(매수 증가량−매도 증가량)·증가량 가중 매수/매도 추정가격, 최근 1분 순매수 속도(계약/분), 최근 5분의 수급·선물가격 방향을 표시합니다. 창이 아직 차지 않았으면 부분 관측으로 표시합니다. 같은 초의 관측은 초 단위 버킷으로 묶어 계산량을 제한하며 경계에서 최대 약 1초의 포함 차이가 있을 수 있습니다. 이 값들은 공급자의 누적 수량과 관측 당시 공통 선물 체결가를 결합한 추정치이며 실제 외국인 체결원가·순포지션이나 인과적 매매 신호가 아닙니다. 원천 RTD 시각이 연결되지 않은 항목은 수집 시각 기준입니다.

`변동성 · 위험` 탭에는 완료 1분 RV 변화의 관측 표준편차와 별도의 일별 현물금리 기반 위험예산 연구 수량이 표시됩니다. 시작할 때 오늘 파일을 읽어 당일 관측 이력을 복원합니다. 재실행 공백을 하나의 수익률 변화나 신호 지속시간으로 연결하지 않으며, 과거 알림이나 과거 매매 판단도 재생하지 않습니다. 1분 변화 변동성은 실제로 연속 관측된 인접 분 변화만 사용합니다. 수동 DV01이 비어 있으면 실행 시점의 신선한 3년·10년 선물수익률 RTD로 KRX 표준채권 이론 DV01을 계산해 해당 실행 세션 동안 고정합니다. 연구 수량은 아래 입력이 충족될 때만 계산합니다. 선물 실현손익이나 실제 운용 수량으로 해석하지 마세요. 초기 설계 원칙과 장중 지표의 차이는 [원칙 재검토](docs/PRINCIPLES_REVIEW_20261016.md)를 참고하세요.

## 가격대 알림

대시보드의 `가격 알림 설정`에서 다음 기준을 `이상`, `이하`, `구간`으로 설정할 수 있습니다.

- 10년−3년 선물 체결가 차(pt)
- 10년−3년 선물 수익률 차(bp): 수익률이 % 단위이면 차이에 100을 곱합니다. 기준값도 bp로 입력합니다.
- 현물 10년−3년 체결수익률 차(bp)
- 현물 3−5−10년 곡률(bp)
- 3년·10년 현선물 수익률 베이시스와 교차 베이시스(bp)
- 3년 또는 10년 선물 체결가

조건이 1초 이상 유지되면 작업표시줄의 대시보드 버튼을 5회 점멸하고 화면 왼쪽 아래에 알림 팝업을 띄웁니다. 팝업의 테두리와 제목 배경은 0.7초마다 깜빡이며 ‘확인 · 닫기’를 누를 때까지 유지됩니다. 표시된 숫자는 알림 발생 당시 값입니다. 새 알림은 기존 팝업을 교체하며, 소리가 켜져 있으면 발생 시 0.09초 길이의 낮은 음량 알림음을 한 번 냅니다. 조건 안에 머무는 동안 새 알림을 반복 발생시키지는 않으며, 설정된 재무장 폭만큼 기준에서 이탈한 뒤 다시 진입해야 재알림됩니다. 지연 데이터에는 알림을 내지 않습니다.

현재 `추가RTD`에는 원천 갱신시각 셀이 없으므로 수집 PC 시각으로 최신 여부를 확인합니다. RTD 공급값 자체가 동결된 경우를 완전히 판별하지 못합니다. 추후 원천 시각 셀을 추가하면 `extra_settings.json`의 시간 항목에 연결할 수 있습니다.

## 외국인 수급 관측 가격대

외국인 누적 매수·매도 수량의 직전 관측 대비 증가분을 그 시점의 선물 체결가와 선물수익률로 가중해 매수·매도별 추정 평균 및 주 관측 가격구간을 표시합니다.

```text
관측 매수 추정가격 = Σ(외국인 누적매수 증가량 × 관측 선물체결가) / Σ증가량
관측 매도 추정가격 = Σ(외국인 누적매도 증가량 × 관측 선물체결가) / Σ증가량
```

당일 첫 관측 이전 누적량은 현재 가격에 소급하지 않습니다. 날짜/세션 변경이나 누적량 감소 시 주구간을 초기화합니다. 10초 초과 공백·잘못된 체결가·지연된 원천시각에서도 이미 관측한 당일 주구간과 시간창 안의 관측 수급은 유지하되, 연속 관측 충족시간은 다시 계산합니다. 공백 중 증가한 수량은 어느 가격에도 배정하지 않습니다. 대시보드 재시작 시 오늘 CSV의 기존 행을 나누어 읽어 외국인 수급과 변동성/RV 창을 복원하며 그 과정에서 알림은 발생하지 않습니다. 수집기가 꺼져 기록되지 않은 체결은 복원할 수 없습니다. 참가자별 개별 체결가·거래대금이 없기 때문에 이는 실제 외국인 평균체결가가 아니라 RTD 관측 간격에 의존하는 추정치입니다.

외국인별 실제 체결가·보유원가·미결제 포지션은 현재 연결된 RTD의 투자자 유형별 누적 매수·매도 수량만으로 식별할 수 없습니다. 외국인별 완전한 체결 원장, 시작 잔고 및 계약월별 포지션 자료가 없는 상태이므로 해당 세 값은 화면에서 미제공으로 표시합니다.

## 일별 현물금리 위험예산과 시간순 검증

현물 일별 CSV에는 `date,cash_3y_yield_pct,cash_10y_yield_pct` 열이 필요합니다. 날짜는 `YYYY-MM-DD`, 수익률은 `%` 숫자이며 날짜가 오름차순·중복 없이 있어야 합니다. `settings.json`의 `risk.cash_history_csv`는 로컬 `data/cash_daily.csv`로 설정되어 있습니다. 현재 로컬 파일은 2025-01-02~2026-10-15의 434일치이며 GitHub에는 올리지 않습니다. 원본 `기획팀/한국채_금리_조회결과.xlsx`가 갱신되면 아래 명령으로 다시 변환하고 대시보드를 재시작하세요. 변환에 `openpyxl`이 필요합니다.

```powershell
python .\import_cash_yields.py '.\기획팀\한국채_금리_조회결과.xlsx' '.\data\cash_daily.csv'
```

DV01 수동값이 없을 때는 연결된 선물수익률로 자동 계산합니다. 위험 수량을 내려면 별도로 `risk.capital_krw`, `risk.annual_target_vol_fraction`(예: 0.10), `risk.max_package_count`를 입력해야 합니다. 마지막 현물금리 날짜가 수량 계산 기준일보다 `risk.cash_history_max_age_days`(기본 4일)를 초과해 오래됐으면 수량을 차단합니다. 이는 달력 일수 기준이며 국내 휴장일 달력을 자동 판별하지 않습니다. 데이터 CSV가 없는 다른 PC에서는 위험 수량을 미연결로 표시합니다.

한 패키지의 일별 손익 **대용치**는 `3년 정수계약수 × 3년 DV01 × 3년 현물금리 변화(bp) − 10년 계약수 × 10년 DV01 × 10년 현물금리 변화(bp)`입니다. 최근 60개 변화와 최근 20개 변화의 표본 표준편차 중 큰 값을 위험 추정치로 사용합니다. 일간 목표 위험액은 `자본 × 연간 목표 변동성 / √252`이며, 이를 1패키지 위험 추정치로 나눈 값을 정수로 내림한 뒤 패키지 수·설정된 총/잔여 DV01 한도로 제한합니다. 현재 날짜의 미완료 관측값은 화면 계산에 포함하지 않으며, CSV 또는 설정을 바꾸면 대시보드를 다시 열어야 합니다. 현물금리와 선물가격 간 베이시스·계약월·실행 중 DV01 재산출·증거금·실제 포지션은 반영되지 않습니다.

시간순 검증은 미리 정한 평가 시작일을 인수로 전달합니다. 시작일 이전 최소 252개, 이후 최소 60개 일별 변화가 있어야 숫자를 냅니다. 각 평가일의 예측에는 그 전날까지의 금리 변화만 사용하며, 결과는 현물 10Y−3Y 금리차의 **일별 변화 위험 예측**입니다. 선물 매매전략의 OOS 수익률 검증은 아닙니다.

```powershell

```

평가 시작일은 데이터 기간에 맞춰 결과를 보기 전에 정해야 합니다. 현재 로컬 187일 표본은 기본 요건(평가 전 252일 + 평가 후 60일)에 미달합니다. 2026-07-01 시작 검사는 학습 119일·평가 67일로 `insufficient_history`를 반환합니다. 장기 데이터가 추가되기 전까지 OOS 합격이나 선물전략 검증을 주장하지 않습니다.

## 저부하 동작

- Excel RTD polling: 정상 시 1초(100~2000ms 설정 가능), 연결 오류가 연속되면 3→4→5초 간격 재시도
- 로그: 호가나 체결가가 바뀌면 즉시 기록, 변화가 없으면 5초마다 상태 기록
- 디스크 반영: CSV와 SQLite를 1초 단위로 묶어 반영
- 대시보드: 시작할 때 최근 행만 읽고 이후에는 새로 추가된 행만 분석
- 콘솔: 클릭 실행에서는 매 polling 출력하지 않고 오류만 `launcher.log`에 남김

수집 간격을 늘려도 CheckExpert RTD 자체의 끊김이나 공급값 동결을 해결했다고 볼 수는 없습니다. 1초 사이에 잠깐 닿은 가격은 놓칠 수 있으며, 알림은 관측된 값에 대해서만 동작합니다. 0 호가처럼 Excel 연결은 유지됐지만 시세가 유효하지 않은 경우에는 연결 오류 백오프가 아니라 정상 1초 주기로 재확인합니다.

모든 polling 행이 필요한 진단 상황에서는 `--log-all`을 추가할 수 있습니다.

## 다중 시간대 RV 신호

대시보드는 같은 RV level을 두 시간대로 분리해 표시합니다.

- 빠른 RV: 최근 120개 실제 가격변화 이벤트. 대시보드·수집기·로그 분석기 모두 120개가 쌓이기 전에는 z-score 신호를 내지 않음
- 주 RV: KST 기준 최근 완료된 60개 분의 마지막 관측값. 진행 중인 분은 참조 평균에서 제외하며, 60개가 쌓이기 전에는 신호를 내지 않음
- 종합 판단: 두 z-score가 같은 방향으로 진입 임계값을 넘고 조건이 3초간 유지될 때만 `두 시간대 확인`으로 표시. 비용 기준을 충족하지 못하면 진입 보류
- 초기화: KST 날짜 변경·10초 초과 공백·불량 행에서 재준비. 이는 거래소 야간 세션 달력 구현이 아님

창 길이, beta, 진입·청산 임계값은 `settings.json`에서 바꿀 수 있습니다. 기본 beta `2.88`은 검증 완료된 DV01 값이 아니라 기존 연구값입니다.

`risk.dv01_3y_krw_per_bp`와 `risk.dv01_10y_krw_per_bp`가 모두 비어 있으면 대시보드는 실행 시점의 신선한 선물수익률로 표준채권 DV01을 계산합니다. 계산은 액면 1억원, 연 5% 쿠폰, 반기 지급, 잔존 3년·10년 가정이며 beta는 `DV01_10Y / DV01_3Y`입니다. 세션 도중 beta를 바꿔 가짜 RV 변화를 만들지 않도록 재실행 전까지 고정합니다. 수동값 두 개를 모두 입력하면 자동값보다 우선합니다. 자동값은 실제 보유채권·계약월별 바스켓·포트폴리오 DV01이 아닙니다. [KRX 3년 상품명세](https://global.krx.co.kr/contents/GLB/02/0201/0201040501/GLB0201040501.jsp), [KRX 10년 상품명세](https://open.krx.co.kr/contents/OPN/01/01040503/OPN01040503.jsp)

## RV 해석 기준

대시보드의 기본 RV z-score는 마지막 체결가 변화량이 아니라 호가 mid 기반 상대가격 수준을 표준화합니다. mid 자체는 체결 가능한 가격이 아닙니다.

```text
RV level = 10Y mid - beta × 3Y mid
RV z-score = (현재 RV level - rolling 평균) / rolling 표준편차
```

체결가는 RV level의 기준값이 아니라 시장 거래 확인용으로 함께 저장됩니다. 빠른 창 전체인 120개 가격 변화 이벤트가 쌓이기 전에는 `데이터 축적 중`으로 표시합니다. `±2` 임계값과 beta `2.88`은 KTB 데이터로 검증 완료된 매매 규칙이 아닌 초기 연구용 값입니다.

## 최근 디버깅 기록

2026-10-19 점검에서는 대시보드가 10/16의 저장 기록을 표시했고 수집기는 기존 CSV와 새 행의 열 구성이 달라 종료됐습니다. 현재는 오늘 날짜 파일만 선택하고 기존 기록을 재생하지 않으며, 선택적 RTD 값이 비어도 저장 열 구성이 변하지 않게 수정했습니다. 기존 로그는 삭제하지 않았습니다. **수집기 창과 대시보드 창을 모두 닫고**, Excel의 RTD 값이 실제 갱신되는지 확인한 다음 위 순서로 다시 시작해야 수정 코드가 적용됩니다. 오늘 파일이 없으면 화면은 `오늘 실시간 데이터 대기`와 `신호 차단`을 표시합니다. 원천 RTD 시각이 없는 항목은 수집 시각만으로 공급자 데이터의 당일 갱신을 증명할 수 없습니다.

추가로 Windows CMD에서 깨진 한글 파일명 검사 때문에 실행 배치가 workbook을 못 찾을 수 있어, `실시간_호가_시작.bat`의 검사를 ASCII wildcard인 `*.xlsx`로 바꿨습니다. Excel이 생성하는 `~$*.xlsx` 임시 잠금 파일은 Git 추적 대상에서 제외합니다.

## 데이터 구조

호가·체결가 워크시트는 `Sheet1`, 추가 지표 워크시트는 `추가RTD`입니다. `Sheet1`의 3Y 심볼은 `KBFA020`, 10Y 심볼은 `KXFA020`입니다. 체결가는 `G2`(3Y), `O2`(10Y)이며 RTD 필드는 `15001`입니다.

| 데이터 | 3Y | 10Y |
|---|---|---|
| Ask price | `D2:D6` | `L2:L6` |
| Ask quantity | `C2:C6` | `K2:K6` |
| Bid price | `D7:D11` | `L7:L11` |
| Bid quantity | `E7:E11` | `M7:M11` |
| Trade price | `G2` | `O2` |

## 주의

기본 beta `2.88`은 선물수익률이 없을 때만 쓰는 초기 연구값입니다. 정상 수익률이 연결되면 실행시점 표준채권 DV01 비율을 세션 beta로 사용합니다. OBI/WOBI와 z-score 임계값은 아직 국채선물 데이터로 검증된 매매 기준이 아닙니다.
